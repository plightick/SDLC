# Высота и длина

**Автор:** Апанас Е.Э.  
**Группа:** 450503  
**Дисциплина:** Жизненный цикл разработки программного обеспечения (ЖЦРПО)

## Описание проекта

Настольное Java-приложение для пересчёта длины между единицами измерения
(метр, сантиметр, дюйм, ярд и наглядные бытовые единицы).
Пользователь вводит значение, выбирает исходную и целевую единицы,
получает результат в графическом интерфейсе.

Каркас исходного кода находится в каталоге `project/`.
Шаблоны проектной документации (SRS, SDD, ADR) сохранены в корне репозитория.
