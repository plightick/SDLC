# Серверный рендеринг страниц на Thymeleaf

## Контекст и постановка задачи

Пользовательский интерфейс — каталог с фильтрами, формы загрузки, страница материала, кабинет и страницы модерации (REQ-INT-001). Адаптивность от 360 пикселей, русский язык. Как формировать страницы?

## Драйверы решения

* Минимум отдельных технологий и сборок при одном исполнителе.
* Защита от CSRF и XSS (REQ-SEC-003).
* Вход и роли на стороне сервера (REQ-FUNC-001, REQ-FUNC-002).

## Рассмотренные варианты

* Серверный рендеринг (Spring MVC + Thymeleaf)
* Одностраничное приложение (React) и REST API
* Серверный рендеринг с вкраплениями htmx

## Итог решения

Выбранный вариант: «Серверный рендеринг Spring MVC + Thymeleaf», потому что страницы формируются там же, где проверяются права и данные, не нужен отдельный API и клиентская сборка, а защита от CSRF и экранирование вывода включены в Spring Security и Thymeleaf по умолчанию.

### Последствия

* Хорошо, потому что один проект и один язык; меньше кода на итерациях.
* Хорошо, потому что поисковый запрос и фильтры работают обычными ссылками и формами.
* Плохо, потому что богатые интерактивные элементы (просмотр документа) приходится подключать отдельными скриптами (ADR 0007).
* Нейтрально, потому что при необходимости REST API добавляется позже без переписывания сервисов.

### Подтверждение

Автотесты MockMvc для страниц каталога и загрузки; проверка адаптивности в Chrome и Firefox от 360 px (W-6).

## Плюсы и минусы вариантов

### Thymeleaf

* Хорошо, потому что встроенная защита и простота.
* Нейтрально, потому что интерактивность ограничена.

### Одностраничное приложение

* Хорошо, потому что богатый интерфейс.
* Плохо, потому что вдвое больше работ: API, клиентская сборка, управление токенами.

### Thymeleaf + htmx

* Хорошо, потому что частичные обновления страниц без SPA.
* Нейтрально, потому что добавляет зависимость, польза проявится в версии 1.1.

## Дополнительная информация

Связанные требования: REQ-INT-001, REQ-SEC-003, REQ-SEC-004. Представления SDD: 002-composition, 005-interface.
